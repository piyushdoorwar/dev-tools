How conversion works

CSV → JSON

  • Parsing follows RFC 4180: fields may be wrapped in double quotes, a quote inside a quoted field is written "", and quoted fields may contain delimiters and line breaks.
  • Auto-detect picks whichever of comma, semicolon, tab, or pipe appears most often in the first line, ignoring anything inside quotes.
  • With Header row on, each row becomes an object keyed by the first line. Blank headers become column_3, and repeated headers get a suffix such as id_2 so no value is lost. With it off, each row becomes an array.
  • Infer numbers & booleans turns 42, -1.5, true, false, and null into JSON types. Numbers with leading zeros, such as ZIP codes like 02134, stay strings.

JSON → CSV

  • Accepts an array of objects, an array of arrays, or a single object. Columns are the union of every object's keys, in the order they first appear.
  • Nested objects are flattened into dotted columns, so {"user":{"name":"Ada"}} becomes a user.name column. Arrays are written as JSON text.
  • Fields containing the delimiter, a quote, a line break, or leading or trailing spaces are quoted. Auto-detect writes commas.

Table

  • Click a column header to sort ascending, again for descending, and a third time to restore the original order. Numbers sort numerically.
  • Sorting and filtering change the table only. The JSON or CSV output always keeps the source order.
  • Large files show the first 1,000 matching rows; use the filter to narrow them down.
