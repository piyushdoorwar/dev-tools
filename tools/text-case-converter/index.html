How word splitting works

Case styles

  • camelCase — first word lowercase, each following word capitalized, no separators. Used for JavaScript variables and function names.
  • PascalCase — every word capitalized, no separators. Used for class names and React component names.
  • snake_case — lowercase words joined by underscores. Used for Python variables and SQL column names.
  • kebab-case — lowercase words joined by hyphens. Used for URL slugs, CSS classes, and file names.
  • CONSTANT_CASE — uppercase words joined by underscores. Used for constants and environment variables.
  • Title Case — every word capitalized, separated by spaces. Used for headings and document titles.

Boundaries

  • Spaces, hyphens, underscores, dots, and other punctuation always split words.
  • A lowercase letter or digit followed by an uppercase letter splits too, so fooBar becomes foo / Bar.
  • A run of capitals followed by a capital-plus-lowercase splits before the last capital, so XMLParser becomes XML / Parser.
  • Every word is lowercased before it is rebuilt, so the output case comes entirely from the target style, not from whatever casing the input happened to use.

Whole text vs. line by line

  • Whole text treats the entire input, including line breaks, as one identifier.
  • Line by line converts each line on its own, so a list of phrases becomes a matching list of identifiers in the same order, one per line.
