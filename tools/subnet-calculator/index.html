# Subnet Usable range Last

    How it works

    Input

    • Type a block as 10.0.0.0/16, an address with a netmask as 10.1.2.3 255.255.0.0 or 10.1.2.3/255.255.0.0, or an IPv6 block such as 2001:db8::/48.
    • An address with host bits set is fine: the tool shows the network it belongs to.
    • A bare address is read as a single host, /32 or /128.
    • IPv4 octets with leading zeros such as 010 are rejected, because some systems read them as octal and others as decimal.

    Usable hosts

    • IPv4 subnets reserve the first address (network) and the last (broadcast), so a /24 has 254 usable hosts.
    • A /31 is the exception: on point-to-point links both addresses are usable (RFC 3021). A /32 is a single host route.
    • IPv6 has no broadcast, so every address in the block counts.

    Tools

    • Split divides the block into equal subnets by prefix length, or by the number of hosts each one needs.
    • Contains checks whether an address or a smaller block falls inside the block.
    • Range → CIDR turns a first and last address into the smallest list of CIDR blocks that covers exactly that range. Click a block to open it.

    Everything is calculated in your browser.
