Using Unicode / Character Inspector

Each row is one Unicode code point, not one grapheme. A visible character can comprise several code points. Hidden, control and combining characters are flagged rather than displayed as blank cells.

UTF-16 bytes are big-endian without a BOM. Lone surrogates cannot be encoded as valid UTF-8. Names and categories come from bundled Unicode 17.0 data, with a limit of 5,000 code points.

Copy text as JavaScript code-point escapes, HTML hexadecimal entities or CSS escapes. HTML and CSS replace invalid scalar values such as lone surrogates when interpreted.
