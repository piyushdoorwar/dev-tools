Reading the inspector

One row per code point, not per grapheme. An emoji such as 👩🏽‍💻 is one grapheme made of four code points, so the status bar counts both.

  • Hidden means it renders as nothing or as an ordinary space: format characters such as ZWSP, ZWJ, BOM and bidi marks, control characters, variation selectors and non-standard spaces such as NBSP. They show as a badge and are counted in the summary.
  • Whitespace is drawn as ␠ ⇥ ↵, and combining marks sit on a dotted circle ◌́. Neither counts as hidden.
  • Remove hidden strips every hidden character, including the ZWJ and variation selectors inside emoji sequences, so a joined emoji splits into its parts.
  • UTF-16 bytes are big-endian without a BOM. A lone surrogate has no valid UTF-8 form; HTML, CSS and URL output replace it with U+FFFD when read.
  • Non-ASCII only leaves printable ASCII as it is, but still escapes controls and the characters that would break a string in that format, such as \ and quotes. URL mode keeps only A–Z a–z 0–9 - . _ ~.
  • CSS escapes end with a space only when the next character is a hex digit or whitespace, which is when CSS needs one.
  • Names and categories come from bundled Unicode 17.0 data. The table shows up to 5,000 code points; the counts and escapes cover the whole text.
