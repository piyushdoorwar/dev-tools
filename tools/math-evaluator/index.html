Math / Expression Evaluator

Calculate expressions, exact BigInt arithmetic, and percentages with a session history.

Operators: + − * / % ^ (power). Functions: sqrt, log (natural), log10, sin, cos, tan, abs, floor, ceil, round, min, max. Constants: pi, e. Trigonometry uses radians. Add n to integer literals for BigInt; do not mix BigInt and decimal numbers. BigInt division truncates. Ordinary numbers use floating-point arithmetic and may round.

Percentages

Percentage change uses (B − A) / |A| × 100. A zero starting value is undefined.
