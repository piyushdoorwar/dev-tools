Using the placeholder generator

Everything updates as you type. The image is built in this tab and never uploaded.

  • Pick a preset such as Open Graph (1200 × 630) or a 300 × 250 ad, or type any size from 1 to 10,000 px. The swap icon flips width and height.
  • Blank text shows the size, e.g. 640 × 360. Text is escaped, so < and & are safe.
  • Auto font size scales with the image and shrinks for long text. Type a number, or pick Custom, to set it yourself.
  • Colours take #RGB or #RRGGBB. The swatch follows the hex field as you type.
  • Output formats: raw SVG, a URL-encoded data URI, a Base64 data URI, an <img> tag, or a CSS background-image.
  • Download saves the SVG, or a PNG rendered from it at 1× or 2×.
