    How it works

    Reading a User-Agent

    • A UA is a list of product/version tokens and (comments). The first comment usually holds the OS, device and CPU.
    • Most tokens are compatibility lies: every browser says Mozilla/5.0, Chromium browsers also claim Safari/537.36, and WebKit says like Gecko. The parser checks the most specific token first — Edg/ before Chrome/ before Safari/.
    • Safari's version is in Version/; its Safari/ token is the frozen WebKit build.
    • Every browser on iOS and iPadOS uses WebKit, so CriOS, FxiOS and EdgiOS are Chrome, Firefox and Edge skins over Safari's engine.
    • Brave, Arc and Vivaldi send exactly Chrome's UA. Nothing in the string tells them apart.

    UA reduction and frozen values

    • Chromium froze most of its UA to cut fingerprinting: minor versions are always .0.0.0, Windows is always NT 10.0 (so Windows 10 and 11 look the same), and Android is always Android 10; K.
    • Safari, Chrome and Firefox all report macOS as 10_15_7 (Firefox: 10.15) on every release since Catalina, and say Intel on Apple Silicon too.
    • iPadOS Safari asks for desktop sites with a Mac UA by default, so an iPad can look like a Mac.

    Why Client Hints are more reliable

    • User-Agent Client Hints (navigator.userAgentData and the Sec-CH-UA-* headers) give structured values rather than a string to sniff: real brands, platform version, architecture and model.
    • High-entropy values are only sent when asked for, via getHighEntropyValues() or an Accept-CH response header. On Windows, a platform version of 13 or higher means Windows 11.
    • Only Chromium browsers implement them. Firefox and Safari don't, so there the UA string is all there is. The Client Hints panel always describes this browser, not the string you pasted.

    Bots

    • Known crawlers (Googlebot, Bingbot, GPTBot, ClaudeBot…), HTTP libraries (curl, python-requests, Go-http-client…) and headless browsers are flagged. Any client can send any UA, so verify real crawlers by reverse DNS or their published IP ranges.

    Everything is parsed in your browser; nothing is sent anywhere.
