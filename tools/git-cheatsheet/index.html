Using the Git cheatsheet

Finding a task

  • Search matches every word in any order across titles, commands, notes and categories: untracked stash finds the stash task.
  • Narrow the list with the category menu. The category is kept in the address, so a link opens on the same list.
  • Each command line has its own copy button, so a multi-step task is run one step at a time.

Reading the badges

  • Rewrites history — commits get new IDs. Harmless on commits only you have; once pushed, the branch needs a force push and everyone who pulled it has to repair their copy.
  • Discards work — uncommitted changes or commits can be lost. Run git stash -u or create a branch first if you are unsure.
  • No badge means the command only adds or inspects.

Placeholders

  • Highlighted names such as <branch> and <file> are yours to replace.
  • Fill in branch, commit, file or tag in the Placeholders bar and every command, and every copy, uses your value. Empty ones are copied as-is.
  • Values are inserted exactly as typed. Quote a path that contains spaces.
  • main and origin are written literally; change them if your repository uses other names.

Never rewrite pushed, shared history

  • If others may have pulled a commit, undo it with git revert instead of reset, amend or rebase.
  • On your own pushed branch, force-push with --force-with-lease, never plain --force.
  • Something went wrong? git reflog remembers where every branch pointed for about 90 days.

Uses git switch and git restore (Git 2.23+); the notes give the older checkout and reset forms. In PowerShell, quote stash names: 'stash@{0}'.
