    About these hashes

    Everything runs locally. Text and files are hashed in this tab and never uploaded.

    • Text is hashed as UTF-8. Line breaks are \n, so a file saved with Windows line endings hashes differently — use File mode to hash the exact bytes.
    • Watch the trailing newline. echo "abc" | sha256sum hashes abc\n. Use printf %s "abc" or echo -n to match this tool.
    • MD5 and SHA-1 are broken for security. Collisions are practical. They are still fine as checksums against accidental corruption, not against tampering.
    • HMAC (RFC 2104) keys the hash with a secret, which is how webhook signatures such as GitHub's X-Hub-Signature-256 are made. Keys longer than the block size are hashed first; an empty key is allowed.
    • Compare accepts hex in either case or Base64, and takes the first word, so a pasted sha256sum line works as-is.
