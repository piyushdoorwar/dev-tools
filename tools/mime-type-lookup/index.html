Using MIME Type Lookup

Search in either direction, then copy the Content-Type header using the icon on its right. Filename extensions are hints, not validation of file contents.

Content-Type describes the body; Content-Encoding describes compression. Use charset=UTF-8 for text when appropriate. Let the browser set multipart boundaries for FormData.

Unknown binary data commonly uses application/octet-stream. This is a common-type reference, not the complete IANA registry.
