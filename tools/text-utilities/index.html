How the counts work

Definitions

  • Characters counts code points, so an emoji or an accented letter counts once rather than twice.
  • Words are runs of non-whitespace, which is what word processors count. Hyphenated words count once.
  • Sentences end at . ! ? or …, so abbreviations such as “e.g.” inflate the number slightly.
  • Reading time assumes 200 words per minute, speaking time 130.

Token estimate

  • The token figure is an estimate for English text in GPT-style byte-pair encoders: roughly one token per four characters of a word, plus one for each punctuation mark and line break.
  • It is calculated locally — no text leaves the browser — so it cannot match a model's real tokenizer exactly. Treat it as ±10–20% for prompt budgeting, and check the real count before paying for a long run.
  • Code, non-English text, and long unusual words tokenize more heavily than this estimate suggests.

Cleaning order

  • Operations always run in the order shown above the output: trim, collapse, drop empty lines, dedupe, sort, recase, number. The pipeline line names the steps that are actually active.
