Converter Tips

Quick Guide

Type in any box to update the others instantly. Separate numbers with spaces or commas.

UTF-8 / Text
Text is encoded as UTF-8 bytes, so ASCII and international text round-trip consistently.
Binary (Base 2)
Used for raw bits in computers. Enter as 8-bit groups like 01001000.
Hexadecimal (Base 16)
Compact for bytes. Common in programming, colors, memory addresses. Use 2-digit groups.
Decimal (Base 10)
Human-friendly byte values from 0 through 255.
Octal (Base 8)
Legacy and Unix permissions. Use 3-digit groups for bytes.

Integer mode

  • Type one whole number in any base 2–36. With Auto-detect, 0x, 0b and 0o prefixes pick the base; anything else is read as decimal.
  • _ and spaces are digit separators, so 1_000_000 and ff ff both work.
  • Values are arbitrary-precision (BigInt) — 2^200 converts exactly.
  • Negative numbers are shown sign-magnitude (-ff); the two’s complement view wraps them into the chosen width and warns when a value doesn’t fit.
  • Radix-32 here is plain base 32 (digits 0–9, a–v), not the RFC 4648 byte encoding.
