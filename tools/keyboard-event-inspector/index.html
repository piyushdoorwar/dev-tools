Using Keyboard Event Inspector

Events are captured only while the keyboard input area has focus. Press a key to see its logical key, physical code, location, modifiers, repeat state and composition state. History keeps the latest 30 keydown events.

Tab and Escape are not intercepted. OS and browser shortcuts may never reach the page. The keyCode property is deprecated; use key or code for new shortcuts.
