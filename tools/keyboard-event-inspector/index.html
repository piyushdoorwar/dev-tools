How capture works

Keys are read only while the capture area has focus. It takes focus when the page opens; if the status says Not focused, click it once. Nothing is sent anywhere.

  • key vs code. key is the character the layout produced ("A", "é", "Dead" for an accent key). code is the physical position (KeyA) and ignores layout, Shift and CapsLock.
  • Pick the match for your shortcut. Match on key for mnemonic shortcuts like Ctrl+K; match on code for position-based ones such as WASD, which should stay put on AZERTY. The combo uses the physical key, so Shift+1 reads as 1, not !.
  • The condition only checks the modifiers you held. Add !e.altKey and friends if Ctrl+Alt+K must not also fire Ctrl+K.
  • location tells left from right: 0 Standard, 1 Left (ShiftLeft), 2 Right (ShiftRight), 3 Numpad.
  • Tab and Escape are not intercepted, so you can always leave the capture area with the keyboard. Ctrl and Meta combinations are not blocked either, so browser shortcuts such as copy, reload and close tab keep working. Some OS shortcuts never reach the page at all.
  • Modifier chips are live. They light up on keydown and release on keyup; leaving the window releases them too, because the browser drops that keyup.
  • keyCode and which are deprecated. They are shown for old code you may be reading; use key or code in new work.
