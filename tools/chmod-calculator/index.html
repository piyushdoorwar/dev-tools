    Common values

    A umask is a mask, not a mode. The shell starts from 666 for a new file and 777 for a new directory, then removes every bit the mask names. Files never get execute from the base, which is why 022 yields 644 and not 755.

    How Unix permissions work

    Three classes, three bits each

    • Owner (u), group (g), others (o) each get read 4, write 2 and execute 1. Add them up and you have one octal digit per class.
    • Only the first matching class applies. A file owned by you with mode 077 gives you nothing, even though the group and others have everything.

    Execute is not what it looks like on a directory

    • On a file, execute runs it. On a directory, execute is the right to traverse — to reach anything inside, including by exact path.
    • Read without execute on a directory lists the names but cannot stat them. Execute without read reaches a known filename but cannot list. That asymmetry is why 711 exists.
    • Deleting a file is governed by the write bit on its directory, not on the file. This is what the sticky bit exists to restrain.

    The fourth digit

    • 4 setuid — the program runs as its owner. 2 setgid — as its group, or on a directory, new entries inherit the group. 1 sticky — only a file's owner may delete it.
    • A capital S or T in the symbolic form means the special bit is set but the matching execute bit is not — usually a mistake.

    The mode is only half of it: what a user may do also depends on the owner and group of the file, the mount options, and on Linux, any ACL or SELinux policy in the way.
