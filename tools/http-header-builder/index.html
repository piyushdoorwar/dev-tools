Using HTTP Header Builder

Choose Basic, Bearer or API key, fill in the values, then build the header. Copy actions sit at the right of each output panel.

Basic uses UTF-8 Base64. The server must support UTF-8 credentials; a username cannot contain a colon. Decoding splits at the first colon so passwords can contain additional colons.

Basic is not encryption. Use HTTPS. Credentials are neither saved nor sent by this tool. The curl command quotes values for a POSIX shell.
