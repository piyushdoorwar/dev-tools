Which tags each platform reads

                    
                

                

                    

                        
Everything runs locally. Tags are built in this tab. The preview image is only fetched when you press Load image, and is requested with no referrer.

                    

                    
    
                        
  • Google uses <title>, meta description and rel="canonical". It truncates titles near 60 characters and snippets near 160, and may rewrite either.
    • 
                        
  • Facebook, LinkedIn and Slack read Open Graph: og:title, og:description, og:image, og:url.
    • 
                        
  • X needs twitter:card; it falls back to og:* for the title, description and image. With an image the card is summary_large_image, otherwise summary.
    • 
                        
  • Images: 1200 × 630 (1.91:1), PNG or JPEG, under 5 MB. Keep text away from the edges, since some surfaces crop to a square.
    • 
                        
  • URLs must be absolute and use HTTP or HTTPS. A relative /og.png is ignored by crawlers.
    • 
                        
  • Previews are cached. Re-scrape with the Facebook Sharing Debugger or LinkedIn Post Inspector, or change the image URL (?v=2) to force a refresh.
