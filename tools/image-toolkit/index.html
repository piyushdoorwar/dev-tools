    How this toolkit works

    Everything stays local

    Detection, decoding, conversion, icon rendering, SVG optimization, previewing, and download all happen inside your browser. Nothing is uploaded by this tool.

    What metadata cleanup means

    With stripping enabled, the tool draws decoded pixels into a fresh image and omits standard embedded metadata. It does not remove information visible in the pixels, external provenance records, or every possible watermark.

    Format boundaries

    SVG and BMP can be rendered to PNG, JPEG, or WebP. Raster-to-SVG is not offered because wrapping pixels in an SVG is not true vector conversion. Animated GIFs are rejected rather than silently losing animation.

    Icon packs

    Each size is drawn from the source image rather than resampled from a smaller icon, so nothing is upscaled twice. The ZIP carries the PNGs, a multi-resolution favicon.ico, site.webmanifest, and the markup to paste into your head.

    SVG optimization

    The document is parsed, not regex-edited: editor metadata, comments, empty groups and redundant precision are dropped, and the result is re-serialized. Rendering is compared by eye — check the preview before shipping a heavily rounded path.
