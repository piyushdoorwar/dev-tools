Encoding Reference

Everything runs locally.

Text is treated as UTF-8 in every mode, so accented and emoji input round-trips.

Base64
The standard A–Z a–z 0–9 + / alphabet with = padding. Wrapping at 76 characters matches MIME.
Base64url
RFC 4648 §5: + becomes -, / becomes _, and padding is usually dropped. This is what JWTs use.
URL — Component
encodeURIComponent. Escapes reserved characters such as / ? & = #, so it is the right choice for a single query value or path segment.
URL — Full URL
encodeURI. Leaves the characters that give a URL its structure intact, so use it when escaping a whole address.
File
Encode drops a file into a data: URI (with its MIME type) or raw Base64, ready for CSS, HTML or JSON. Decode takes either one, previews images and text, and downloads the bytes. Without a data: prefix the type is detected from the file's signature — PNG, JPEG, GIF, WebP, PDF, ZIP and more.
HTML Entities
Markup only escapes & < > " '. All non-ASCII additionally escapes every character above U+007F as a numeric reference. Decoding resolves named and numeric references alike.
