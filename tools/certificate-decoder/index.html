What this decodes

Accepted input

  • CERTIFICATE — one X.509 certificate or a whole chain pasted together. Each block gets its own tab.
  • CERTIFICATE REQUEST — a PKCS#10 CSR, including the SANs it asks for.
  • PUBLIC KEY and RSA PUBLIC KEY — SPKI and PKCS#1 keys.
  • Binary .der / .cer files, bare Base64 DER, and Base64 of a whole PEM file (a Kubernetes tls.crt value).

What you get

  • Validity — a status of valid, expiring within 30 days, expired, or not yet valid, measured against your clock.
  • Chain checks — each certificate is matched to its issuer in the paste, and the signature is verified with WebCrypto when the browser supports the algorithm.
  • SPKI pin — the Base64 SHA-256 of the public key, the value used for certificate pinning.

Privacy

  • Everything is decoded in this page. Nothing is uploaded and no network request is made.
  • Private keys are recognised and deliberately not decoded.
